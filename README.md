# Firm Library — Releases

Public download location for the **Biblioteca do Escritório** application.

The source code lives in a private repository. This repository holds only the
built release artifacts for each version:

- `firmlib-<versão>.tar.gz` — pacote do código (requer Python instalado).
- `firmlib.exe` — executável autónomo para Windows (não requer Python).

Descarregue a versão mais recente em **[Releases](../../releases/latest)**.
